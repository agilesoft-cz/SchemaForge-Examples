SchemaForge-Examples
Example databases and generated applications for SchemaForge

This repository contains sample SQL Server databases intended
to be used as inputs for SchemaForge.

Typical workflow:

1. Clone this repository.
2. Publish the selected database project.
3. Create a new empty Visual Studio solution in your own repository.
4. Run SchemaForge against the published database.
5. Commit the generated application to your own source-control system.
